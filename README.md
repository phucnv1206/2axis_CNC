## Overview
This is a simple 2-axis CNC plotter that uses a servo motor to raise and lower the pen, and 28BYJ-48 stepper motors with GT2 belts for movement. Drawing area: 120 x 120 mm.

The machine’s motion design is inspired by the Bambu Lab A1 Mini 3D printer. The entire frame is designed and 3D-printed.

This project was developed for educational purposes, so it is not designed for high precision. All components are common and readily available, making the project easy and affordable to build.

This is the first version of the project, so there are still some known issues that have not yet been fixed. **Please use the machine with caution.**

---

## Features
- Quick and easy connection
- Connect to the plotter quickly with a simple setup process.
- Simple image-to-line conversion
- Start drawing quickly without the need for complex or in-depth configuration.
- Large drawing area for a wide range of drawing projects.
