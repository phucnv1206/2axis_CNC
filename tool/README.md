## CNC Tool
The tool is built using HTML, CSS, and JavaScript, making it easy to access directly from a web browser without installing additional software.

Since it runs entirely as a web-based tool, users can work with their files directly in the browser without having to install an application that may require unnecessary access to personal data or system resources.

---
## Features
- Freehand Drawing:
Draw directly on the canvas using a mouse or touchscreen.
- Image Upload: 
Upload images directly to the tool for processing and plotting.
- Image-to-Path Conversion: 
Convert images into drawable paths, then transform these paths into coordinates that can be sent to the plotter.
- Flexible Drawing Position and Scale: 
Adjust the drawing position and size, allowing flexible placement of the paper or workpiece on the drawing surface.
- Direct Machine Control:
Control the plotter directly through the tool, including movement and drawing operations.
